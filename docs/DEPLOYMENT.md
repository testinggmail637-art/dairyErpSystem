# Deployment (production)

Target: one Linux VPS (Ubuntu 22.04/24.04) with **Nginx + PHP-FPM 8.3+ + MySQL 8**, Laravel scheduler via cron,
queue worker and Pulse server monitor under **Supervisor**. No Node/npm build step — front-end libraries are
committed in `public/vendor/`.

Paths below assume the app lives in `/var/www/dairy-erp` and runs as `www-data`. Adjust to your server.

---

## 1. Server packages

```bash
sudo apt update
sudo apt install -y nginx mysql-server unzip git supervisor \
  php8.3-fpm php8.3-cli php8.3-mysql php8.3-bcmath php8.3-mbstring php8.3-xml php8.3-curl \
  php8.3-zip php8.3-gd php8.3-intl
# Composer 2: https://getcomposer.org/download/
```

`bcmath` is **required** (all money/quantity maths). `mysqldump` (from `mysql-client`) is required for backups.

PHP settings (`/etc/php/8.3/fpm/php.ini` and `/etc/php/8.3/cli/php.ini`):

```ini
date.timezone = Asia/Kolkata
upload_max_filesize = 5M      ; receipts ≤ 2 MB, login background ≤ 3 MB
post_max_size = 8M
memory_limit = 256M
expose_php = Off
```

Restart: `sudo systemctl restart php8.3-fpm`.

### Performance tuning (the app holds years of daily records — keep pages under 1 s)

PHP OPcache (`/etc/php/8.3/fpm/conf.d/10-opcache.ini`):

```ini
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=20000
opcache.validate_timestamps=0   ; code changes only on deploy → run `sudo systemctl reload php8.3-fpm` after each deploy
```

PHP-FPM pool (`/etc/php/8.3/fpm/pool.d/www.conf`), for a 4 GB VPS: `pm = dynamic`, `pm.max_children = 20`,
`pm.start_servers = 4`, `pm.min_spare_servers = 2`, `pm.max_spare_servers = 6`, `pm.max_requests = 500`.

MySQL (`/etc/mysql/mysql.conf.d/mysqld.cnf`): give InnoDB about half the RAM of a dedicated DB server
(`innodb_buffer_pool_size = 2G` on 4 GB), `innodb_log_file_size = 256M`, and turn on the slow log to catch slow
queries Pulse reports: `slow_query_log = 1`, `long_query_time = 0.5`.

Always run `php artisan optimize` after deploying (cached config, routes, views, events).

## 2. Database

```sql
CREATE DATABASE dairy_erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'dairy_user'@'localhost' IDENTIFIED BY 'a-long-random-password';
GRANT ALL PRIVILEGES ON dairy_erp.* TO 'dairy_user'@'localhost';

GRANT PROCESS ON *.* TO 'dairy_user'@'localhost';
FLUSH PRIVILEGES;
```

Do **not** create `dairy_erp_test` on the production server — tests never run there.

## 3. Get the code and install

```bash
sudo mkdir -p /var/www/dairy-erp && sudo chown $USER:www-data /var/www/dairy-erp
git clone git@github.com-me:testinggmail637-art/dairyErpSystem.git /var/www/dairy-erp   # private repo (deploy key)
cd /var/www/dairy-erp
composer install --no-dev --optimize-autoloader     # --no-dev: Telescope is NOT installed in production
cp .env.example .env
php artisan key:generate
```

Edit `.env` (checklist in section 4), then:

```bash
php artisan migrate --force
php artisan db:seed --force          # roles & permissions, default farm, owner user, master data
php artisan storage:link
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R ug+rwx storage bootstrap/cache
php artisan optimize                 # caches config, routes, views, events
```

Log in with `OWNER_EMAIL` / `OWNER_PASSWORD`, then **change the password** from My profile.

## 4. `.env` production checklist

| Key | Production value | Why |
|---|---|---|
| `APP_ENV` | `production` | Disables debug helpers; Telescope never loads |
| `APP_DEBUG` | `false` | **Never `true` in production** — it shows secrets on error pages |
| `APP_URL` | `https://erp.yourdairy.in` | Correct links in notifications and PDFs |
| `APP_KEY` | generated by `key:generate` | Encrypts sessions; keep it secret, keep a copy offline |
| `APP_TIMEZONE` | `Asia/Kolkata` | All dates in IST |
| `DB_CONNECTION` | `mysql` | MySQL 8 |
| `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | from section 2 | |
| `DB_DUMP_BINARY_PATH` | empty | `mysqldump` is on the PATH on Linux |
| `OWNER_NAME`, `OWNER_EMAIL`, `OWNER_PHONE`, `OWNER_PASSWORD` | real values | The seeder refuses the local defaults in production |
| `SESSION_DRIVER` | `database` | |
| `SESSION_SECURE_COOKIE` | `true` | Cookies only over HTTPS |
| `CACHE_STORE` | `database` | |
| `QUEUE_CONNECTION` | `database` | Background jobs (worker in section 7) |
| `MAIL_*` | not needed | No email in v1 |
| `PULSE_ENABLED` | `true` | System Monitor at `/pulse` |
| `PULSE_SLOW_REQUESTS_THRESHOLD` / `PULSE_SLOW_QUERIES_THRESHOLD` / `PULSE_SLOW_JOBS_THRESHOLD` | `1000` / `500` / `1000` | Milliseconds |
| `SENTRY_LARAVEL_DSN` | DSN from sentry.io | Error alerts (empty = off) |
| `SENTRY_TRACES_SAMPLE_RATE` | `0.2` | 20 % of requests traced |
| `TELESCOPE_ENABLED` | `false` | Belt and braces (the package is not even installed with `--no-dev`) |
| `BACKUP_DISKS`, `BACKUP_PATH`, `BACKUP_ARCHIVE_PASSWORD` | see `docs/BACKUP_RESTORE.md` | |
| `LOG_LEVEL` | `warning` | Smaller logs |

After every `.env` change: `php artisan config:cache`.

## 5. Nginx

`/etc/nginx/sites-available/dairy-erp`:

```nginx
server {
    listen 80;
    server_name erp.yourdairy.in;
    root /var/www/dairy-erp/public;
    index index.php;

    client_max_body_size 8M;
    charset utf-8;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header Referrer-Policy "strict-origin-when-cross-origin";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    # Long cache for versioned assets (asset_v() adds ?v=<mtime>)
    location ~* \.(css|js|woff2?|ttf|svg|png|jpg|jpeg|webp|ico)$ {
        expires 30d;
        access_log off;
        try_files $uri =404;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 120;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/dairy-erp /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
# HTTPS (free certificate):
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d erp.yourdairy.in
```

## 6. Scheduler (cron)

Runs backups (02:00 / 02:30 / 03:00 IST) and, in later phases, delivery sheets and reminders.

```bash
sudo crontab -u www-data -e
```

```cron
* * * * * cd /var/www/dairy-erp && php artisan schedule:run >> /dev/null 2>&1
```

Check: `php artisan schedule:list`.

## 7. Supervisor: queue worker + Pulse server monitor

`/etc/supervisor/conf.d/dairy-erp.conf`:

```ini
[program:dairy-erp-queue]
command=php /var/www/dairy-erp/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
process_name=%(program_name)s_%(process_num)02d
numprocs=1
user=www-data
autostart=true
autorestart=true
stopwaitsecs=3600
redirect_stderr=true
stdout_logfile=/var/www/dairy-erp/storage/logs/queue.log

[program:dairy-erp-pulse]
command=php /var/www/dairy-erp/artisan pulse:check
user=www-data
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/www/dairy-erp/storage/logs/pulse.log
```

```bash
sudo supervisorctl reread && sudo supervisorctl update
sudo supervisorctl status
```

`pulse:check` feeds the **Servers** card (CPU, memory, disk). Pulse uses its default `storage` ingest driver, so no
`pulse:work` process is needed. If the ingest driver is ever switched to Redis (`PULSE_INGEST_DRIVER=redis`), add a
third program running `php artisan pulse:work`.

## 8. Monitoring

| Tool | Where | Who / notes |
|---|---|---|
| **Laravel Pulse** | `https://erp.yourdairy.in/pulse` (Settings → System Monitor) | Only users with permission `monitoring.view` (owner by default); admin and staff get 403. Shows slow requests (> 1000 ms), slow queries (> 500 ms), exceptions, queues, slow jobs, cache, busiest users, server stats. Data kept 7 days |
| **Sentry** | sentry.io project | Create a Laravel project, copy its DSN into `SENTRY_LARAVEL_DSN`, `php artisan config:cache`. Configure alert rules (email / mobile app) on sentry.io. Personal data is not sent (`send_default_pii = false`). Test: `php artisan sentry:test` |
| **Telescope** | `/telescope` | **Local development only.** Not installed with `composer install --no-dev`, never registered unless `APP_ENV=local` |
| **Logs** | `storage/logs/laravel.log` | `tail -f storage/logs/laravel.log` |

## 9. Deploying an update

```bash
cd /var/www/dairy-erp
php artisan backup:run --only-db          # safety copy first
php artisan down --retry=60
git pull --ff-only origin main
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan db:seed --class=RolesAndPermissionsSeeder --force   # new permissions (keeps role edits)
php artisan optimize:clear && php artisan optimize
php artisan queue:restart
php artisan pulse:restart
php artisan up
```

Front-end files have no build step; `asset_v()` adds the file's modification time so browsers fetch new CSS/JS.

## 10. Troubleshooting

| Problem | Check |
|---|---|
| 500 error, blank page | `storage/logs/laravel.log`; permissions on `storage` and `bootstrap/cache`; `php artisan optimize:clear` |
| Changes to `.env` ignored | `php artisan config:cache` (config is cached in production) |
| `/pulse` shows "Table … doesn't exist" | `php artisan migrate --force` |
| Pulse Servers card empty | Supervisor program `dairy-erp-pulse` not running: `sudo supervisorctl status` |
| Backups not created at 02:00 | Cron entry missing (section 6); see `docs/BACKUP_RESTORE.md` |
| Jobs stuck | Queue worker not running; `php artisan queue:failed` |
| Uploads give 413 | Raise `client_max_body_size` (Nginx) and `upload_max_filesize` / `post_max_size` (PHP) |
